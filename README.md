# Mudavath Santhosh Portfolio

A cinematic, responsive portfolio for Mudavath Santhosh, AI Full-Stack Developer.

## Live portfolio

Visit the deployed site: [santhoshportfolio-pied.vercel.app](https://santhoshportfolio-pied.vercel.app)

## Features

- Dark cinematic design with responsive navigation and animated portrait.
- AI Full-Stack Developer profile, skills, project work, and experience and education.
- Downloadable resume, email contact, GitHub profile, and LinkedIn profile.

## Run locally
Open `index.html` directly, or serve the folder with any static server.

Example:
```bash
python -m http.server 8080
```
Then open http://localhost:8080

## Important
- GitHub and LinkedIn buttons link to the profiles supplied for this portfolio.
- The resume is served from `assets/santhosh-resume.pdf` and linked from the hero and Contact sections.
- Email links open a Gmail compose window addressed to the portfolio owner; this static site does not send or store messages itself.
